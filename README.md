# 🎓 Trombinoscope ENI — Promo EDWM2605FT

Projet web réalisé dans le cadre de la formation **Développeur Web et Web Mobile (Bac+2)** à l'ENI.

## 📋 Présentation

Application web permettant de visualiser et d'explorer les apprenants de la promotion EDWM2605FT de l'ENI.

## ✨ Fonctionnalités

- **Affichage en liste ou en cartes** — bascule dynamique selon les préférences
- **Thème clair / sombre** — personnalisable et sauvegardé entre les sessions
- **Carte interactive** — localisation géographique des apprenants
- **Page Informations** — présentation de la formation et liens utiles
- **Préférences persistantes** — sauvegardées dans le LocalStorage

## 🛠️ Technologies utilisées

- HTML5 sémantique
- CSS3 (Flexbox, Grid, Variables CSS, Media Queries)
- JavaScript Vanilla (fetch, localStorage, DOM)
- JSON pour les données

## 📱 Responsive Design

Le site est adapté aux différents formats d'écran (mobile, tablette, desktop).
